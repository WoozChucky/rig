# Tagged Unions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Unions that know which member they hold. `Shape :: union #tagged { circle: Circle; rect: Rect; empty: void; }` lays out a tag (the smallest unsigned integer that counts the members, or `union #tagged u32`) and then the members over each other, as C's `struct { tag; union { ... }; }`. A value is made with one member by name (`Shape.{circle = c}`, `.{rect = r}`), or `Shape.empty` / `.empty` for a `void` member; a zeroed one holds its first member, zeroed. Its members are read only in a switch, `if s == { case .circle; ... it ... }`, which must name every member or have `case;`, `it` being the member in the union itself (a place when `s` is one). `s == .empty` and `s != .circle` test the tag. It works compiled, interpreted and in a `#run`, as globals and constants; `type_info` describes it (`.TAGGED_UNION`, 32, `Type_Info_Tagged_Union`); Basic's `print` writes `.circle({r = 2})` and `.empty`; gdb and cdb show a struct of the tag (as an enumeration of the member names) and a union of the members; C gets it through a pointer.

**Architecture:**
- **Parser and AST:** after `union`, the directive `#tagged` and an optional integer type name make `Ast_Struct.is_tagged` and `tag_expr`. A tagged union's braces hold named members only.
- **Types:** a tagged union is a `TYPE_STRUCT` with `Type.is_tagged` and `Type.tag_type` (its tag at offset 0), its `fields` the members, all at the one offset after the tag, a `void` member a field of type `void`. Copies, pointers, `Any`, arrays, fields of it, circles and untyped `.{}` carry over from structs; layout, literals, member access, the switch, comparison, folding, baking, description, printing and debug information look at the flag.
- **Checker:** `check_member` refuses `s.circle`; `Shape.empty` and `.empty` become a literal the checker makes (`made`); literals record their member (`Ast_Literal.tag`); `check_switch` takes a tagged union, its cases naming members (`Ast_Case.member`), and binds `it` per case (`Ast_Case.it`); `check_binary` makes `s == .empty` a tag test (`Ast_Binary.tag_member`).
- **Lowering:** a literal zeroes, stores the tag, then its member; the switch takes the switched value's address once, reads the tag, dispatches with the existing `IR_SWITCH` and no-case helper, and each case's `it` is that address plus the members' offset, no copy.
- **`#run`, type information, Basic, debug information:** a baked tagged union is its tag and its live member's value; `describe_type` writes a `Type_Info_Tagged_Union`; `print_item` gains a branch; the backend makes a struct of an anonymous enumeration `tag` and an anonymous union.

**Tech Stack:** C-style C++23, built with the pinned clang 23.1.5 (`build.bat`, `build.sh`), no STL; LLVM 23.1.5's C API; Rig for Preload and Basic; JavaScript (Node) for the VS Code extension's checks; gdb and cdb for the debugger tests.

**Spec:** GitHub issue #224 (`gh issue view 224`), whose Decisions are settled design; section 4 of the milestone's design, `docs/superpowers/specs/2026-11-22-milestone-5-type-system-design.md`, whose scope, non-goals, anti-goals and constraints bind every task; and `docs/rig-spec.md`, which each task updates for what it builds. ## Decisions this plan makes

1. **One PR, four tasks**, each green on both hosts, each a reviewer's gate:
   1. Declare and check tagged unions (parser, AST, types, layout checked against clang's, literals, member refusal, the switch's checks, `it`, tag tests; no lowering).
   2. Compile and run them (lowering, constants and globals, `#run`, C by pointer, the debug types, the runtime error).
   3. Describe and print them (`Type_Info_Tagged_Union`, Preload, Basic's `print`).
   4. Show them in gdb and cdb.

   Until Task 2 nothing lowers a tagged union: Task 1's tests are unit tests and `tests/errors` only, its spec examples ```` ```rig fragment ```` or ```` ```rig error ````. Until Task 3 no test prints a whole tagged union or describes one.
2. **A tagged union is a struct with a flag**, as #223's union is: `Ast_Struct.is_tagged`, `Type.is_tagged`, `TYPE_STRUCT`, `is_union` false. A new kind would repeat every place a struct value goes. `Type.fields` holds the members in order, each at the members' offset (`fields[0].offset`; Decision 5), a `void` member's type `&type_void`; `Type.tag_type` is the tag's integer type, always at offset 0. Every walker of a struct's fields that a tagged union reaches (`walk_struct`, `describe_members`, the debug types, `bake_value`, `constant_bytes`, `lower_literal`) handles a `void` field (size 0, nothing to read or write).
3. **Syntax.** `NAME :: union #tagged [IDENT] { member; ... }`, at the top level only. Members are `IDENT ':' Type ';'`; an anonymous member inside is refused, and so is `union #tagged` as an anonymous member, and `struct #tagged` (messages above); at least one member, said by the parser at the name (with none there is no zero value: Decision 6). The type after `#tagged` is a name only, as an enum's is. `#tagged` after a signature joins `#complete` and `#through` in the directive loop's list that ends in `expected '{', found directive`; anywhere a value goes it's `expected an expression, found directive`, as other directives. Dump: `(union #tagged Shape _ (circle Circle) (empty void))`, `(union #tagged Big u32 (a int))`.
4. **The tag type.**
   - Without one: the smallest unsigned type that holds every tag, 0 to n-1: `u8` up to 256 members, `u16` up to 65536, else `u32`.
   - Chosen: any built-in integer type, signed too, since a C binding's tag is often an `int`; resolved in the layout as `check_enum_members` resolves an enum's (behind a pointer); anything else is `a tagged union's tag must be an integer type, not 'float32'`, and the tag is then the default. It must hold n-1 (`s8` holds 127): otherwise `a 'u8' tag can't count the 257 members of 'Big'`, and the union has no type (as one too big). An enum as the tag type is not in this plan.
5. **Layout** (in `lay_out`, by `s->is_tagged`, two passes, since every member's alignment is needed before any offset): the tag at 0; the members all at `align_up(tag size, A)`, A the largest member alignment (1 when every member is `void`); the alignment the larger of the tag's and A; the size `align_up(members' offset + largest member size, alignment)`. That is C's `struct { T tag; union { ... }; }` (checked against the pinned clang in Task 1). A `void` member has size 0 and alignment 1 (`resolve_type_or_void`). A late member (a pointer) is laid out from what's written, as a struct's. Holding itself by value, directly or through structs, arrays, unions or tagged unions, is `contains itself`, as a struct's; behind a pointer, a view or a resizable array it's allowed. Two members of one name: `'x' is already declared at PATH:L:C`.
6. **Zero value and literals.** A zeroed tagged union is tag 0, its first member's bytes zero: `s: Shape;` and `emit_zero` need nothing new. A literal gives exactly one member, by name, as the issue says, so `Shape.{}` and values in order are `a tagged union's literal names its one member, ...`; a second member, the same member twice and a name it lacks are refused as above; a `void` member can't be given a value (`'Shape.empty' holds nothing; write Shape.empty`). The checker sets `Ast_Literal.tag` to the member's index and `fields` to `{index}`. Untyped `.{rect = r}` meets a tagged union through `check_convert`'s struct path. Lowering zeroes the temporary, stores the tag (`tag_type`, at 0), then the member at its offset.
7. **`void` members as values.** `Shape.empty` (an `Ast_Member` whose operand names the tagged union: `of_tagged`, as `of_enum`) and `.empty` meeting a tagged union (`convert_member`) are the value holding that member: the checker makes the literal it means and keeps it in the node's `made` (`Ast_Member.made`, `Ast_Dot_Name.made`); lowering lowers `made`, `constant_data` answers with it (so `E :: Shape.empty;` is constant data, and a global's value), and the node is no place. A member that isn't `void` written so is `'Shape.circle' holds a 'Circle'; make one with Shape.{circle = ...}`. `.A | .B` meeting a tagged union is refused by `convert_member`'s existing operator message (`'|' needs integers, not 'Shape'`).
8. **Tag tests.** In `check_binary`, `==` or `!=` with a tagged union on one side and a member's name on the other, `.NAME` or `Shape.NAME`, either order, any member (`void` or not), is a `bool`: `operand_type` the tagged union and `tag_member` the member's index; the name isn't checked as a value (so `Shape.circle` there is no error), and a name the union lacks is `'Shape' has no member 'z'`. When the union is constant data (`constant_data` reaching a literal), the test folds, so `#if E == .empty` works. Anything else compared with a tagged union by `==` or `!=`, another tagged union, `null`, a number, is `'==' compares a tagged union only with a member's name, as in s == .empty`; order operators keep `'<' needs numbers, not 'Shape'`. Lowering: the union's address (`lower_expr`), the tag loaded at 0, compared with the index.
9. **Members are read only in a switch.** `check_member` refuses any member of a tagged union (or of a pointer to one), reading, writing, `*s.x`, in a `#run` too, since all go through it: `a tagged union's member is read in a switch: if S == { case .NAME; ... it ... }`. `S` is the operand as written, its source text from its start to the `.` before the name, trailing spaces cut, when that lies on one line, `s` otherwise; through a pointer `S` is that text and `.*`, since `if p == {` would switch on the pointer. `NAME` is the name written.
10. **What a switch takes.** `is_switchable` takes a tagged union too, so its message becomes `a switch needs an integer, an enum, a bool, a string, a pointer or a tagged union, not 'float64'` (Fact 12's places change with it). A pointer to a tagged union is still a pointer switch.
11. **A tagged union's switch.**
    - Each case's value is a member's name, `.circle` or `Shape.circle` (`Shape` the switched type), looked up by one helper shared with the tag tests; anything else is `a tagged union's case names one of its members, as in case .circle;`. `Ast_Case.member` holds the index; the value node gets the tagged type and no constant.

    - Every member needs a case unless there's a `case;`: the missing ones, in member order, in one message at the `if` (Messages). A switch with every member and a `case;` is fine: the `case;` runs only for a tag C wrote out of range.

12. **`it`.**
    - Each case naming a member that isn't `void` gets `Ast_Case.it`, an `Ast_Var` named `it`, at the `case`, of the member's type, `is_case_member` set, declared in the case's own scope before its statements (as `check_for` declares an iterator), so it hides any outer `it`: a loop's, an outer switch's. Inside the case a loop's or an inner switch's `it` hides it in turn.

Each case's `it` is that address plus the members' offset, computed in the case's block: no copy, so a write through `it` lands in the union, and a case that assigns the whole union a new value then reads the new bytes through `it` (the program's business, as reading the wrong member of a C union is; the spec says so).
13. **No case at run time.** A tagged switch without `case;` meeting a tag no member has (C wrote it, or memory was overwritten) calls the existing `__rig_no_case` at the `if`: `runtime error: no case for value 7 of 'Shape'`, the design's one wording for enums and tagged unions, the value read by the tag type's sign (`emit_no_case` takes the tag type for the value and the union for the name). ## Not in this plan

- Passing a tagged union, or any struct or union, to and from C by value: #236, milestone 6 (Decision 16).
- An enum as a tagged union's tag type (`union #tagged Kind`), a chosen tag value per member, and a tag offset other than 0.
- Naming a case's binding (`case c: .circle;`), several members in one case, and `#through` in a tagged switch (Q2).
- Reading a member outside a switch in any form (`s.circle`, a checked or unchecked accessor), and comparing two tagged unions.
- Anonymous members inside a tagged union, a tagged union as an anonymous member, and tagged unions declared in a body.
- `using` on a tagged union's members (#225), overloading operators on tagged unions (#9 of the milestone), generic tagged unions (#7).

## Settled by the maintainer

- **Q1. Baking a `#run`'s tagged union:** (a), its tag and its live member's value: a string or view member is copied, a non-null pointer refused, as in a struct (Decision 15).
- **Q2. `#through` in a tagged union's switch:** (a), refused everywhere: each case sees only its own member.
- **Q3. `it` in a `void` member's case and in `case;`:** (a), not declared, so an outer `it` stays visible there.
